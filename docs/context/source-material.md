# 비공개 원본 자료 지도

**언제 읽나** — 1인칭 문장을 쓸 때. 옛 기록의 근거를 찾을 때. 책노트를 이어받을 때.
**어떤 자료가 어디 있는지 모를 때 여기부터 본다.**

`_원본자료/`는 **gitignore 대상이다.** 이 저장소는 공개이므로 그 안의 내용은
`docs/`·`content/`·`CLAUDE.md` 어디에도 원문으로 옮기지 않는다. **가리키기만 한다.**

## 읽는 표기

세 파일이 같은 표기를 쓴다. **섞어 읽지 않는다.**

- **`[사실]` / `[패턴]`** — 글에 그대로 적혀 있거나 센 것
- **`[읽음]` / `[추측]`** — 여러 글을 겹쳐 읽어낸 것. **틀렸다고 말하기 쉽게 적은 것이다**
- **`[?]`** — 근거가 한쪽뿐이라 물어야 하는 것
- **`[후보]`** — 나란히 놓기만 한 것. 이어졌다고 확정한 것이 아니다

본인이 정한 역할 분담이 이 표기의 근거다 — **패턴을 세는 것은 Claude, 그 의미를 정하는
것은 같이.** 해석과 추측은 표시한다.

## 현재 작업 상태는 여기가 아니다

무엇이 끝났고 무엇이 남았는지는 `HANDOFF.md`. 이 폴더는 **재료**이지 작업 상태가 아니다.
